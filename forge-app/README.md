# Forge Android

APK Android instalable de Forge.

La APK contiene la interfaz completa y realiza las llamadas de IA/API desde Android. El Forge Engine Node (filesystem, Git y procesos reales) permanece como componente separado para Termux; no se simula dentro de la APK.

## Compilar
GitHub Actions -> Compilar APK -> Run workflow. El artefacto generado es app-debug.apk.
